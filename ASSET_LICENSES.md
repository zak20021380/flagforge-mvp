## Dwarf Warrior

BRAX's battlefield model is **Dwarf Warrior** by
[Northcliffe](https://sketchfab.com/Samson.Northcliffe.Rydenko), downloaded from
[Sketchfab](https://sketchfab.com/3d-models/dwarf-warrior-b9fcc240bc0642649d39a8ca845b56aa).
It is used under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

The bundled GLB includes the model's meshes, rig, animation, materials, and textures.

## Original project assets

The remaining visible game assets in this MVP are generated by the source code in this repository:

- Battlefield geometry
- Two castle designs
- NYX, VEX, and FUSE articulated unit designs
- Procedural weapons, shields, bows, arrows, flag, props, trees, rocks, bushes, banners, and torches
- UI card portraits and interface styling
- Synthesized sound cues

These original procedural assets are distributed under the same MIT license as the project.
